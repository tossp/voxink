## Windows 分层验证

以下示例把唯一 JSON 报告从 stdout 重定向到文件；固定提示与参数错误仍写入 stderr：

```powershell
.\voxink-windows-amd64.exe self-check --mode=static --json > .\self-check-static.json
.\voxink-windows-amd64.exe self-check --mode=audio --duration=3s --json > .\self-check-audio.json
.\voxink-windows-amd64.exe self-check --mode=interactive --timeout=15s --json > .\self-check-interactive.json
```

- `static` 可检查构建、运行时、音频契约、会话策略和 controller；它不能证明真实 Windows 设备或桌面交互通过。
- `audio` 必须在 Windows + CGO 的真实麦克风环境运行，只计数并丢弃短采集 PCM。
- `interactive` 验证热键与 overlay 事件路径；焦点是否保持必须由用户人工确认。

## Provider 受控冒烟

仅在 WAV 已获授权发送、账户与供应商当期政策已复核时运行。命令行中不要粘贴 secret；应通过本机受控方式配置凭据。Provider 配置只涉及以下环境变量名称：

- 火山：`VOXINK_VOLC_API_KEY`、`VOXINK_VOLC_RESOURCE_ID`；legacy 可改用 `VOXINK_VOLC_APP_KEY`、`VOXINK_VOLC_ACCESS_KEY`、`VOXINK_VOLC_RESOURCE_ID`。
- MiMo：`VOXINK_MIMO_API_KEY`、`VOXINK_MIMO_AUTH_MODE`、`VOXINK_MIMO_ENDPOINT`。
- 火山可选配置：`VOXINK_VOLC_ENDPOINT`、`VOXINK_VOLC_READ_LIMIT_BYTES`。

每次只调用一个 Provider，不采集麦克风、不触发 fallback：

```powershell
.\voxink-windows-amd64.exe smoke volc --audio .\authorized.wav --confirm-send --json > .\smoke-volc.json
.\voxink-windows-amd64.exe smoke mimo --audio .\authorized.wav --confirm-send --json > .\smoke-mimo.json
```

不要把 WAV、secret 或 Provider 配置上传到 issue、日志或报告附件。

## 报告隐私

自检与 smoke 报告不得包含本地 path、key/secret、endpoint、PCM/WAV、Base64、识别 text、请求或响应 body、raw error。报告使用固定字段和固定错误码，但这不替代人工审阅：用户必须自行检查每份报告，确认符合组织政策后再上传。

## 许可证边界

VoxInk 自身尚未选择 `LICENSE`。`THIRD_PARTY_NOTICES.md` 只提供第三方归属与许可文本，不授予 VoxInk 权利，也不能解读为项目已采用某个开源许可证。本 prerelease 不是 stable，本说明不提供法律结论；项目许可证决策继续由 [#24](https://github.com/tossp/voxink/issues/24) 跟踪。
