# VoxInk v0.1.0-alpha.1

> [!WARNING]
> 这是面向 Windows amd64 的**未签名自动化预览版**。它是 GitHub prerelease，不是 stable，也不是正式可用产品。Windows SmartScreen 可能警告或阻止运行。

## 本次预览包含什么

- 会话核心：`Idle`、`Capturing`、`Transcribing`、`Delivering`、`Stopped`、`Failed` 六态，并用 `SessionID` 拒绝迟到事件。
- 音频切段：500 ms 最短语音、600 ms 连续静音自动切段、15 秒连续语音强制切段、60 秒单会话硬上限。
- ASR：火山 live 主路径；主路径故障时使用 MiMo batch fallback。
- Windows 前端：WASAPI 麦克风采集、默认 `Ctrl+Shift+Space` 全局热键、不会激活或抢占前台焦点的 overlay。
- 诊断：有界结构化脱敏诊断，不记录识别正文、音频、凭据、endpoint、请求/响应或原始错误。
- CI：[Actions workflow](https://github.com/tossp/voxink/actions/workflows/ci.yml) 覆盖 Linux test/race/vet，以及 Windows 2025、`CGO_ENABLED=1` 的 test/vet/未签名 build。workflow 是长期证据入口；具体发布仍应追溯到 tag 所指 commit 的成功运行，而不把某个会变化的 run ID 当作永久唯一证据。

## 下载与 SHA256

发布后请从 [GitHub Releases](https://github.com/tossp/voxink/releases) 下载 `voxink-windows-amd64.exe`，不要把有保留期限的 Actions artifact 当作永久 release。

本 release 将同时附带对应的 `.sha256` 文件。实际 SHA256 由最终 CI artifact 生成后加入 GitHub release body/附件；本文档不写占位值或假摘要。下载后请计算 exe 的 SHA256，并与随附文件中的值逐字比较。

## 运行前提

- Windows x64（amd64）。
- 当前没有安装器：下载后直接运行 exe。
- 在本机设置以下环境变量名称；不要把值写入仓库、issue 或日志：
  - 火山当前认证：`VOXINK_VOLC_API_KEY`、`VOXINK_VOLC_RESOURCE_ID`。
  - MiMo：`VOXINK_MIMO_API_KEY`。
  - 火山 legacy 认证（可选替代当前认证）：`VOXINK_VOLC_APP_KEY`、`VOXINK_VOLC_ACCESS_KEY`，并仍需 `VOXINK_VOLC_RESOURCE_ID`。
- 当前运行流程要求火山主路径和 MiMo fallback 均已配置。火山当前认证与 legacy 认证不能同时使用。
- 默认热键为 `Ctrl+Shift+Space`，用于开始或停止一次会话。

本文档只列环境变量名称，不包含任何密钥值、示例密钥、resource ID 或真实账户信息。

## 隐私与供应商边界

- 收音期间，音频会发送到火山进行实时识别；主路径故障时，同一会话音频可能发送到 MiMo 进行 batch fallback。
- 原始音频默认只保留在当前会话内存中，不落盘。这里不承诺安全擦除，也不对操作系统、运行时或供应商侧的数据处理作超出实现的保证。
- 供应商侧留存、训练、地域和其他处理政策取决于所用账户及当期条款，请在运行前自行核验。
